📋 Shopify Access Token erstellen

  1. Shopify Admin öffnen

    Geh zu admin.shopify.com → Einstellungen → Apps und Vertriebskanäle

  2. Eigene App erstellen

    Klicke auf "Apps entwickeln" → "App erstellen" → Name: "Google App"

  3. API-Berechtigungen setzen

    Wähle: read_products, read_inventory, read_orders (mindestens)

  4. Token kopieren

    Klicke auf "App installieren" → kopiere den Admin API access token

🛒 Google Merchant Center einrichten

  1. Konto erstellen

    Geh zu merchants.google.com und erstelle ein Konto für estid-fashion.de

  2. Shop-URL verifizieren

    Verifiziere www.estid-fashion.de (über HTML-Tag, DNS oder Google Analytics)

  3. Feed hinzufügen

    Geh zu Produkte → Feeds → Primären Feed hinzufügen
    Ziel: Deutschland · Sprache: Deutsch · Typ: URL abrufen
    URL: https://deine-app.com/feed/google-shopping.xml

  4. Feed-Abruf planen

    Stelle den Abruf auf "täglich" ein – die App aktualisiert den Feed automatisch alle 30 Minuten

  5. Google Ads verknüpfen (optional)

    Verknüpfe dein Google Ads Konto für Shopping-Kampagnen unter Einstellungen → Verknüpfte Konten

🚀 App deployen (Empfehlung: Railway)

  1. Repository pushen

    Den Code auf GitHub laden und bei railway.app importieren

  2. Umgebungsvariablen setzen

    In Railway unter "Variables" alle .env-Werte eintragen

  3. Öffentliche URL kopieren

    Railway gibt dir eine URL wie https://estid-google.up.railway.app – diese als APP_URL setzen
